## 0. Strict Anti-Hallucination Guardrails for AI Agents (READ FIRST)

> [!CAUTION]
> **MANDATORY AGENT RULES — DO NOT ASSUME OR INVENT:**
> 1. **Never Invent Packages:** Only use packages already declared in [`pubspec.yaml`](file:///home/your/sarisariApp/pubspec.yaml): `provider`, `intl`, `sqflite`, `path`, `mobile_scanner`, `share_plus`, `path_provider`, `fl_chart`, `image_picker`, `home_widget`, `flutter_local_notifications`, `url_launcher`. Do **NOT** import `flutter_slidable`, `pdf`, `printing`, `shared_preferences`, or `http` unless explicitly instructed and added via `flutter pub add`.
> 2. **Strict Layer Separation:** `UI Screen / Widget` $\rightarrow$ `Provider (ChangeNotifier)` $\rightarrow$ `Repository` $\rightarrow$ `AppDatabase (SQLite)`. UI widgets must **NEVER** call `AppDatabase.instance` or raw SQL queries directly.
> 3. **Centavo Integer Arithmetic Only:** All monetary amounts (`price_cents`, `cost_cents`, `total_cents`, `balance_cents`, `net_worth_cents`) **MUST** be stored and calculated as `int` centavos (`₱1.00 = 100`). Never use `double` or `float` for money storage or summation. Format only at the UI layer using [`CurrencyFormatter.format(cents)`](file:///home/your/sarisariApp/lib/core/utils/currency_formatter.dart).
> 4. **Multi-Table Writes Require SQLite Transactions:** Every operation that modifies more than one table (Sale checkout, Sale void, Restock, Pack break, Utang payment, Activity logging) **MUST** run inside `await db.transaction((txn) async { ... })`.
> 5. **Stock Never Goes Negative:** Enforce `stock_qty >= 0` in both SQLite (`CHECK (stock_qty >= 0)`) and Repository validation before committing.
> 6. **Preserve Existing Test Compatibility:** All 106+ automated tests in `test/` run using `sqflite_common_ffi` with `FLUTTER_TEST` environment detection. Any new native plugin call **MUST** guard against `kIsWeb || Platform.environment.containsKey('FLUTTER_TEST')`.
